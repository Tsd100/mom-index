# 趋势看板

用户已批准板块切换、时间范围、主趋势图、历史点详情及开始每日真实数据积累。

设计：首页以一个可切换的板块主图和样本量图为中心，显示7/30/90天、全部或自定义自然日范围。缺采集日和坏样本保留空点，不跨口径连接；过期最新数据暂停当前判断，带日期的历史仍可查。范围首末变化必须同口径且中间无缺口，并明确实际比较日期。点击图表或选择日期可查原始快照摘要、质量、标的和已有代表帖。
