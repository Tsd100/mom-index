# 每日情绪观察改进计划

用户已批准调研结论中的分类纠错、统一指数解读、每日变化摘要，本轮直接落实。

目标：提高中文否定、提问、转述、亏损表达的处理准确性；每天显示可核查的板块变化。

设计：保留本地分析与静态看板结构，不引入模型依赖。新增独立文本规则模块和摘要模块。摘要只比较紧邻的上次有效同口径日快照，展示比较日期、有效样本数和现有代表帖子；缺少比较、过期或质量不合格时说明原因。新闻背景、完整历史浏览与模型训练留待后续。

- [x] 统一 index_calculator.py、signal.py、dashboard.html 的描述为讨论特征，去除未经验证的买卖与市场顶底判断；历史原件保留。

交付方式：开发分支提交并推送；运行数据不纳入提交。未重新制作 NAS 镜像或部署包。

限制：规则是有限语言模式修正，不能声称解决所有反讽、双重否定或真实投资意图。新旧评分语义版本隔离，不重写生产历史，不自动采集或部署 NAS。
